02 / MEASURE

The gap between target and result.

真实计算误差 · 不把半透明目标当作求解结果

位置误差是映射目标与求解后 Taku FK 参考点之间的距离。姿态误差是两个旋转之间的最短旋转角；肘部只比较位置。

统计来自约 30 Hz 导出的 IK 帧，不是 240 Hz 人体原始采样，也不是实机测量。显示插值不参与统计。

01Skeleton FK源数据提供骨架结构

MHR GLB 的层级、平移、旋转、缩放共同决定世界变换，不假设每个人骨长相同。glTF 单位是米，Y-up → Z-up 只转换一次。

Tworld,j(t) = Tworld,parent(t) · Tparent,j(t)
Wristsl_wrist / r_wristElbowsl_lowarm / r_lowarmShouldersl_uparm / r_uparmPelvis · this sampleroot

这是已优化身体运动，不是网页从视频重新估计人体。手腕无抓取偏移；肘部四元数不进入目标。

02Chest proxy肩中点 + 正交化的躯干轴

L、R 为双肩，H 为骨盆，C = (L + R) / 2。构造 X 向前、Y 向左、Z 沿躯干向上的右手坐标系。

y = normalize(L − R)
u = C − H
z = normalize(u − y(y · u))
x = y × z   →   Rchest = [x y z]

不是额外测得的胸骨点。Taku 胸部参考为 torso_body_link 原点，与人体肩中点不自动等高。

03Footprint proxy骨盆投影 + 固定局部轴

首帧选择最接近胸部前向的骨盆局部轴及符号并固定。后续只随骨盆旋转投影，不逐帧换轴。

pfp = (Hx, Hy, 0)
d(t) = Rpelvis(t) · (sign · ek)
yaw(t) = atan2(dy(t), dx(t))

Aria 世界 z=0 不是独立检测的地面。水平投影退化时，朝向无效。

04A mesh follows a frame.显示旋转 ≠ 记录的姿态

半透明层使用 Taku 真实部件 mesh，但各部件独立跟随目标，不保证组成连通、可实现的机器人。

Tworld,mesh = Tworld,target · Ttarget,mesh

肘只有 xyz；肘 → 腕方向用于推算显示朝向。因此肘点不动、手腕移动时，肘 mesh 仍可旋转。这个显示旋转不产生肘部姿态误差指标。

SOURCE FRAME / RIGHT VIEW

One fixed first-frame alignment.

首帧 footprint 确定水平原点与 yaw；固定变换 A 同时作用于人体骨架与全部源 URR。

T̄i(t) = A · Ti(t)
A = inverse(Tfp(0))

保留源几何及相对参考平面的高度，不是每帧锁回原点。

ROBOT TARGETS / LEFT VIEW

Per-site relative mapping.

从两个人工设定的 Taku 初姿中选一个为锚：首帧双腕平均低于胸部超过 0.50 m 时选垂臂，否则选屈肘。再叠加人体各部位相对首帧的变化。

p*i(t) = probot,i(0) + p̄i(t) − p̄i(0)
R*i(t) = R̄i(t) R̄i(0)T Rrobot,i(0)

这不是统一刚体变换，不保留人体绝对高度或肩宽。初姿选择是可审计的启发式，不是学习策略；初始布局变化不计为跟踪误差。

Source validity ≠ IK limits · 源连续性检查标记手腕/肘超过 4 m/s、胸部/footprint 超过 2.5 m/s 的突变，以及超过 20 rad/s 的姿态突变。这些是可审计启发式阈值，不是人体运动的普适极限。

05 / OUR OFFLINE SOLVE

Tracking without pretending feasibility.

不是在线控制策略或实机实验。

What actually runs.

每帧采用加权阻尼 Gauss–Newton 位置级 IK，从前一帧热启动。21 自由度：平面底盘 3 + 折叠/腰部 4 + 双臂 14。六部位任务共同优化，不是严格层级；最多 24 次迭代/帧，不是固定 120 Hz 速度级求解器。

TARGETS ARE SOFT, NOT MAGIC

Minimize the residual.

将有效位置和朝向残差加权，并加入弱前帧/姿态正则。关节解经 FK 生成实体机器人；目标层独立显示。

minq Σi wp,i ‖pi(q) − p*i‖²
+ Σi wR,i ‖Log(R*iRi(q)T)∨‖²
+ regularization

肘没有朝向项。不可达、冲突或未充分收敛的目标仍会出现误差。

NUMERICAL GUARDS ≠ ACTUATOR LIMITS

Numerically guarded motion.

不使用硬件额定速度/加速度限值，但保留逐帧跳变上限：底盘 x/y 各 0.06 m，yaw / 手臂 0.20 rad，折叠/俯仰 0.15 rad。这会限制等效播放速度，不是“完全无限速”。

qmin,experiment ≤ q ≤ qmax,experiment
|qk − qk−1| ≤ Δqframe
Δq also bounded per numerical iteration

每次迭代另有信赖域及最多 10 次步长减半回溯。逐帧边界不按 dt 缩放；公开运动学描述没有完整硬件限位，实验边界不能宣称符合 Taku 真机能力。

Research note · 之后做速度级跟踪时，前馈有什么作用？

纯位置反馈先产生误差才会追赶。速度级 IK 可用目标线速度与世界系角速度前馈，但应与当前按帧拟合区分。

v* = vd + Kp(pd − p)
ω* = ωd + KR Log(RdRT)∨
J(q) q̇ ≈ [v*; ω*]

居中差分使用未来帧，属于非因果离线估计。角速度来自 SO(3) 对数，而非四元数分量直接做差。这里只解释后续研究思路，不声称本求解器已实现前馈。
