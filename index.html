02 / MEASURE

Tracking, made measurable.

Native samples. No smoothed-away errors.

把“看起来跟得上”变成可以检查的量。位置误差取对应参考点间的欧氏距离；姿态误差取两个旋转之间的最短旋转角。

统计基于源文件的原始采样帧，显示插值不参与统计。缺失或不适用的姿态字段保持为空，不补零。

Why is orientation unavailable?

EGO 的目标有四元数，但 ach.ee 实际末端只公开 xyz；机器人 mesh 能旋转，不代表同一字段记录了实际末端朝向。默认不把缺失值当成 0°。

已启用推导值：Tworld,EE = Tworld,wrist_roll · Twrist_roll,EE。使用公开机器人 link 四元数与固定 EE 变换；位置误差仍保持原始 achieved xyz。源数据经过量化，几何一致性检查不等于独立姿态真值验证。

03 / UNDERSTAND

A representation is a choice.

先明确“这个点是什么”，再讨论它跟得怎么样。

01

Read the source.

分别读取演示轨迹、机器人记录与视频。EGO 演示和 URR Tracking 是不同的数据入口，不把它们当成同一段实验。

02

Name the frames.

区分官方目标、源骨架引导点和推导出的显示朝向。三维模型是参考系的可视化载体，不是额外的传感器测量。

03

Share one clock.

机器人、目标、视频和误差曲线沿同一条相对时间轴回放。拖动到任一时刻，检查动作与数值是否一致。

04

Keep the caveats.

对原始采样做统计，保留缺失字段与源数据限制。目标回放不等于重新求解 IK，也不证明动力学可执行。

DYNA SEMANTICS / TWO DISTINCT SOURCES

半透明 mesh 可以有完整显示姿态，但这并不代表源数据为每个部位都记录了完整姿态。下表专门比较 DYNA 的 EGO 与 Tracking 两个入口；NymeriaPlus 提取定义见下一节。

A mesh follows a frame — not the other way around.

先定义参考点及其朝向，再施加固定的模型局部变换。即便肘点静止，当手腕移动时，连接方向改变，肘部 mesh 也可以旋转；原始肘点的位置并没有因此改变。

04 / HUMAN → REPRESENTATION

Six references, not a copied skeleton.

NymeriaPlus extraction · click each step to inspect the definition.

我们不把每个人体关节一一赋给机器人关节。先用源骨架的层级与局部变换做 FK，再提取任务参考点；只有进一步定义机器人参考系与求解器后，才有机器人关节轨迹。

01Skeleton FK源数据提供骨架结构

标准 MHR GLB 的节点层级、平移、旋转与缩放共同决定世界变换，不假设所有人的骨长完全相同。glTF 轨迹单位是米；Y-up → Z-up 的轴转换只施加一次。

Tworld,j(t) = Tworld,parent(t) · Tparent,j(t)

这里重放已经优化的身体运动，不从视频重新估计人体。没有置信度字段时保持 unknown，不填 100%。

02Wrist & elbow直接节点，不是设备 tracker
Left / right wristl_wrist / r_wristLeft / right elbowl_lowarm / r_lowarmLeft / right shoulderl_uparm / r_uparmPelvis · this MHR sampleroot

手腕保留 FK 的位置与朝向，不加抓取中心偏移。肘部仅取前臂根节点原点的位置；其四元数不作为 URR 肘目标。具体节点映射以样本元数据为准，不靠字段名称猜测。

03Chest proxy肩中点 + 正交化的躯干轴

L、R 是左右肩点，H 是骨盆点。胸部位置 C = (L + R) / 2。下列单位轴构成右手坐标系，X 向前、Y 向左、Z 沿躯干向上。

y = normalize(L − R)
u = C − H
z = normalize(u − y(y · u))
x = y × z   →   Rchest = [x y z]

这是肩部中点代理，不是数据集额外测得的胸骨点。几何退化或连续性异常时标记无效，而不是伪造姿态。

04Footprint proxy骨盆投影 + 固定局部轴

先在有效首帧中，选择最接近胸部前向的骨盆局部轴及正负号。固定这个选择，后续只让骨盆旋转带动它；不会每帧重选一根轴。

pfp = (Hx, Hy, 0)
d(t) = Rpelvis(t) · (sign · ek)
yaw(t) = atan2(dy(t), dx(t))

Aria 世界 z=0 仅为参考平面，不是独立检测的局部地面；水平投影接近退化时，朝向不有效。

SHOWN IN THIS VIEWER

One fixed first-frame alignment.

首帧 footprint 给出水平原点和 yaw，构造一个固定变换 A；所有骨架点与 URR 参考系一起变换。

T̄i(t) = A · Ti(t)
A = inverse(Tfp(0))

点之间的相对几何和相对 z=0 的高度不变；并不是每一帧把身体重新锁回原点。

A LATER RETARGETING STEP

Per-site relative mapping is different.

把人体每个部位相对首帧的运动，叠加到机器人对应参考系的初始位姿。这会改变初始身体布局，不再是同一个刚体变换。

p*i(t) = probot,i(0) + p̄i(t) − p̄i(0)
R*i(t) = R̄i(t) R̄i(0)T Rrobot,i(0)

机器人初姿、参考点偏移、轴修正、人体/机器人的尺度与绝对高度策略都需要明确；本页 Nymeria 模式没有执行这一步或 Taku IK。

Source validity is a separate policy · 原始轨迹的连续性检查与 IK 速度限制不是一回事。当前提取流程会标记手腕/肘超过 4 m/s、胸部/footprint 超过 2.5 m/s 的相邻突变，以及超过 20 rad/s 的姿态突变；这些是可审计的启发式阈值，不是人体运动的普适物理极限。

05 / OFFLINE IK NOTES

Less lag is not the same as feasible motion.

方法说明 · 本网页不运行 IK，不连接机器人

Scope matters.

以下总结此前在另一机器人上的离线 IK 诊断思路，其机器人模型、关节解和误差结果未包含在此公开版本中。不能把这些实验称为 Nymeria → Taku 的性能结果，也不能把网页播放倍率当作求解器速度约束。

Constraint ablation · policies, not performance claims
ConfigurationJoint positionVelocity capAcceleration capWhat it tells us
bounded保留保留保留原始运动学约束下能否追上目标。
no_velocity保留取消保留隔离速度上限；加速度与制动可行性仍可能限制追踪。
position_only保留取消取消同时移除制动约束；仅用于离线诊断，可能出现异常高速、跳变和数值失稳。
stabilized + feedforward保留取消物理速度帽取消物理加速度帽仍保留数值步长保护、阻尼、速度平滑与非线性 FK 验收。

Solver distinction. 原先的 legacy 求解器使用分层 QP；stabilized 版本改为同时加权的软任务速度级 QP，并加入非线性验收与回溯，并不是简单地把同一个严格层级求解器的限速开关关掉。

(qmin − q) / Δt ≤ q̇ ≤ (qmax − q) / Δt

上式表达保留的关节位置边界：下一步仍不能越过关节范围。稳定化方案另有数值步长保护；它不等于电机的物理速度限值。

FOLLOW THE MOTION, NOT ONLY THE ERROR

Velocity feedforward.

纯位置反馈要先产生误差才会追赶。加入目标速度前馈，让任务空间速度既跟随目标本身，也修正当前误差，再通过雅可比求关节速度。

v* = vd + Kp(pd − p)
ω* = ωd + KR Log(RdRT)∨
J(q) q̇ ≈ [v*; ω*]

前馈不能让不可达的点变可达，也不能消除动力学、碰撞和电机能力限制。

OFFLINE DERIVATIVES, EXPLICITLY

One clock for the derivative.

对映射后的目标计算导数，不能对四元数四个分量直接做差分。世界系角速度使用两个旋转之间的 SO(3) 对数。

vd ≈ [p(t + h) − p(t − h)] / 2h
ωd ≈ Log[R(t + h) R(t − h)T]∨ / 2h

既有离线实验在 120 Hz 求解，30 Hz 导出；居中差分使用未来样本，属于非因果离线估计。逐求解步检查峰值，避免 30 Hz 展示隐藏关节跳变。

↗

“Unbounded” should never mean “unchecked.”

物理速度帽与数值信赖域不同。即便关闭速度和加速度上限，仍需限制每步变化、对候选解做非线性 FK 检查并回溯。平均误差更小，不代表可以上真机；这里没有验证动力学、力矩、稳定性或碰撞安全。
